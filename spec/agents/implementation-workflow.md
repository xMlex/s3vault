# Работа перед реализацией

Перед изменением кода:

1. Изучите существующую структуру проекта.
2. Найдите связанные компоненты, модули и зависимости.
3. Поймите существующие архитектурные решения.
4. Найдите аналогичную функциональность, если она уже реализована.
5. Определите минимальный набор изменений.
6. Проверьте потенциальное влияние на существующие интерфейсы и контракты.

Для нетривиальных задач:

- Сначала сформируйте план реализации.
- Определите затрагиваемые компоненты.
- Оцените риски и возможные побочные эффекты.
- Определите стратегию тестирования.
- При существенных архитектурных изменениях предложите альтернативы.

Не приступайте к масштабному рефакторингу без необходимости для текущей задачи.
